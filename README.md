Global Superstore Sales Dashboard

An interactive Power BI report exploring sales, profit, shipping costs, and order geography using the Global Superstore dataset.

## Report pages

- **Landing Page** — overview cards for total sales, total profit, and sales in the United States.
- **Main Panel** — regional sales and shipping cost comparisons, country profit, city and country sales, and an order date slicer.
- **Sales by Country** — country-level sales and profit exploration, with date and country filtering, map visuals, and KPI cards.
- **Sales by Region** — regional sales breakdowns using a treemap, waterfall chart, and decomposition tree, with an order date slicer.
- **DAX Basics** — example summary cards and a product profit margin table.

## Interactive features

The report includes date and country slicers, page navigation, and cross-filter interactions between selected visuals. Open the PBIX in Power BI Desktop to interact with the report.

## File

- `Global_SuperStore_Dashboard_In_Power_BI.pbix` — Power BI report file.

## Open the report

1. Download the `.pbix` file from this repository.
2. Open it with [Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Use the page tabs or page navigation buttons to explore the report and its filters.
